Ansible Vault Editor

v{{version}}

Encrypt, decrypt and edit Ansible Vault files and inline !vault values without leaving the editor. Works in VS Code and VSCodium.

VS Code Marketplace Open VSX Download .vsix

Features

  • Files and inline values: encrypt, decrypt or toggle whole files and single YAML !vault values.
  • Peek and edit decrypted: hover or CodeLens shows a value; edit it in a tab whose plaintext lives only in memory.
  • Save guard and transparent mode: plaintext does not reach disk by accident; optionally decrypt on open and re-encrypt on save.
  • Rekey: one file, or the whole workspace with a preview; vault ID support.
  • Decrypted diffs: in Source Control and, optionally, in git diff.
  • No Ansible needed: a native implementation of the ansible-vault format, byte-compatible with the real tool.

Install

Search for Ansible Vault Editor in the Extensions view, or:

code --install-extension 5mdt.ansible-vault-editor
codium --install-extension 5mdt.ansible-vault-editor

Or download the latest .vsix from GitHub Releases and install it from disk:

code --install-extension ansible-vault-editor.vsix
